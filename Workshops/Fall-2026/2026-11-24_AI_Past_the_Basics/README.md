# Session 7 (Fall 2026): AI Past the Basics

**D-Lab AI Pulse, Fall 2026**: a wide-view session.

24 November 2026.

## The session

Things that go wrong when you work with AI chat tools, and what to do about each. The ideas are ordered by priority for research work, so the session can stop after any of them. Every idea has a numbered title slide and then two slides. The first opens with a question you may recognise from your own use, explains in plain words why it happens, and cites two or three studies. The second, "What Can We Do About It?", gives three pieces of advice, each with an example or a warning sign, and ends with a question for discussion. Nothing needs special software; every idea works in an ordinary chat window.

| What goes wrong | What helps |
|---|---|
| 1. Long chats get worse | Consolidate and start a new chat; keep lasting instructions in a file |
| 2. Exact tasks are where it slips | Offload as much as you can to code |
| 3. It does not catch its own mistakes | Have a different model check the answer, in a new chat |
| 4. It agrees with you | Hide which answer you hope for; ask a question |
| 5. The same question gets different answers | Ask several times, take the majority |
| 6. It guesses what you want | Make it ask you first, or show it an example |
| 7. Big requests get shallow answers | Ask for the plan first, then one step at a time |
| 8. One review covers too much | One job per chat, then one list of problems |
| 9. It answers before it works it out | Switch thinking on; otherwise ask it to work step by step |
| 10. Your first prompt is rarely the best one | Have it write the prompt |
| 11. Confidence is not accuracy | Allow "I do not know"; ask for claims as a list; ask again and compare |
| 12. Its summary is not the paper | Use a tool that answers from your documents, or ask for the quoted passage first |

Sources for every claim are on the last five slides.
