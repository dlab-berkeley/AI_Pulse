# Session 5 (Fall 2026): AI in Science: Workflows

**D-Lab AI Pulse, Fall 2026**: a wide-view session.

27 October 2026.

## The session

Six cases from the past year, each a researcher who handed part of a real project to an AI. The point is not the example but the method: each case is a recipe that works in fields far from its own. Every case runs the same way: the context, the problem and why it was hard before these models, how the model is set up, the method as a tool-agnostic recipe, and the results with what to be wary of.

## The cases

| Field | The example | The method |
|---|---|---|
| Genomics | Labelling 9,000 gene expression experiments (UBC) | A quote for every value; audit the disagreements, in both directions |
| Political science | Coding political texts with a codebook (Harvard) | Disagreement between models as a flag for ambiguous texts and rules |
| Ecology | Screening 19,000 papers for systematic reviews (CSIRO, Tasmania) | Score and rank, never classify; stop by a rule written in advance |
| Materials | Growing a crystal film in an automated lab (Tokyo) | Predict a number before each run, then try to refute it |
| Cosmology | Searching for dark energy models (Brown) | Propose inside a grammar; deterministic gates decide |
| Mathematics | Six open Erdős problems in five days (Columbia) | The prompt as a contract, with adversarial agents |

The deck closes on the sixth case, followed by the sources slide.

Sources for every case are on the last slide.
