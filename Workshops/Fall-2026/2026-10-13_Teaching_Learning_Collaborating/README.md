# Session 4 (Fall 2026): AI for Teaching, Learning and Collaborating

**D-Lab AI Pulse, Fall 2026.** 13 October 2026. Hands-on.

## Description

This workshop looks at how AI is changing three everyday bottlenecks of academic life: learning, teaching, and working with other people. We start from the problems rather than the tools, then work through each one using Gemini Notebook (formerly NotebookLM) and others, with real course and research materials. We close on the question every instructor now faces, which is no longer whether students use AI but what to do about it. Participants should leave with workflows they can use on Monday.

## The six demos

| | Demo | Notebook | What it shows |
|---|---|---|---|
| Teaching | 1. A GSI that never sleeps | Stat 155 course materials | Custom instructions, chat-only sharing |
| | 2. New exams from old ones | 24 synthetic past exams and keys, plus Stat 155 problem sets and exams | Structured generation, and checking it |
| Learning | 3. A tutor for a new literature | Six papers on economic mobility | Learning Guide mode, mind maps |
| | 4. A seminar before the seminar | A fictional working paper, its slides, the literature | An adversarial persona |
| Collaborating | 5. One notebook, three co-authors | Nine documents from a fictional project | Notes, cross-document questions |
| | 6. A lab onboarding tutor | A fictional lab's nine onboarding documents | Chat-only sharing, a safety persona, gaps and conflicts |

Each `demos/demoN_*` folder has `PROMPTS.md` (exact text to paste) and `CUSTOM_INSTRUCTIONS.md` where the demo uses one.

Demos 2, 4, 5 and 6 use synthetic exams, a fictional research project and a fictional lab written for this session. Every page says so.
