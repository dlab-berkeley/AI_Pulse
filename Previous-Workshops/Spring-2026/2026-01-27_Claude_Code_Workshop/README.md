# Coding AI

D-Lab AI Pulse Workshop, Session 1, January 27, 2026

The inaugural session of the series. We introduced AI-powered coding assistants that work directly in the terminal, demoing **Claude Code** and **Gemini CLI** on real research tasks: generating and documenting code, navigating unfamiliar codebases, consolidating messy datasets, and running linear regressions, all through natural language conversation.

## Key Files

- `slides/workshop_slides.tex`: LaTeX Beamer source
- `slides/workshop_slides.pdf`: Compiled slides (30 pages)
- `linear_regression.py`: Demo file used in the linear regression module
- `assets/example_CLAUDE.md`: Example CLAUDE.md project instruction file

## Demo Codebases

The session's larger demo codebases (DSGE.jl, FRED, Michigan, SPF datasets) are not tracked in this repo. See each demo's `SOURCE.md` for download instructions.

## Format

~30 min presentation followed by ~20 min open discussion.
